# 🧾 Vulnerable Shop — 진행 요약 보고서

## 📌 수행 내용

- **프로젝트 개요**
  - PHP + TailwindCSS 기반의 간단한 플리마켓형 쇼핑몰 구축 (취약점 실습 목적)
- **주요 기능 구현**
  - 회원가입 / 로그인 / 마이페이지
  - 상품 목록 / 상품 상세보기
  - 게시판 (글쓰기/조회) / 댓글
  - 장바구니 / 주문(결제 화면) / 주문 내역
  - 관리자 페이지: 대시보드, 상품 관리, 게시글 관리, 회원 관리, 로그
- **UI 프레임워크**
  - TailwindCSS + FontAwesome
- **DB**
  - MySQL 사용
  - 외래키 미사용(조인으로 처리, 에러 대비)
  - 주요 테이블: `users`, `admins`, `products`, `orders`, `order_items`, `board`, `comments`, `logs`
- **기타**
  - 페이지네이션(상품/게시글/회원 관리 등) 컴포넌트 구현 (1페이지당 10~12개)
  - 세션 기반 인증 구현 (`$_SESSION`), 쿠키 사용 안함 (URL 기반 `SID` 옵션 지원)
  - DB 연결 테스트 페이지 생성 (`includes/db_test_user.php`)
  - include 구조(헤더/푸터/헤드 파일)로 리팩토링


## ⚙️ 트러블슈팅

- **문제: 상품·게시글 UI 정렬 깨짐**
  - 원인: Tailwind grid/height 설정 누락
  - 해결: `grid grid-cols-...`와 적절한 크기/spacing 적용

- **문제: 데이터 증가 시 UI overflow**
  - 원인: 페이지네이션 미구현
  - 해결: 페이지네이션 컴포넌트 추가(상품 12개/페이지 등)

- **문제: pico.css로 레이아웃 한계**
  - 원인: 커스터마이징 제약
  - 해결: Tailwind로 전환하여 유연한 UI 구성

- **문제: 마이페이지에서 phone/address 비어있음**
  - 원인: 세션에는 기본 필드(id,name,email)만 저장 → 페이지에서 DB 재조회 누락
  - 해결: `session` → `db_connect` → `SELECT ... FROM users WHERE id=...` 순으로 DB에서 다시 조회하여 채움

- **문제: 로그인 후 세션 유지가 안됨 (마이페이지 접근 불가)**
  - 원인: 쿠키 비사용 환경에서 `SID`(URL 세션파라미터)를 링크/폼에 붙이지 않음
  - 해결: 헤더에서 `SID` 처리 및 모든 내부 링크/폼에 `?PHPSESSID=...` 또는 `?<?= SID ?>` 추가

- **문제: 500 Internal Server Error (로그인 처리)**
  - 원인: 출력 이전에 header/redirect 충돌, 쿼리 에러, 파일 경로 문제 등
  - 해결: 디버그 모드에서 `error_reporting(E_ALL)` 켜고 `mysqli->error` 출력하여 원인 추적
